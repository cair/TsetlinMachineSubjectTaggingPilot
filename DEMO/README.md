# To Run:

> Download the folder DEMO

> Open viewer_demo.html in a web browser

> Upload folder > DEMO/demo_documents

> Choose a sample from the dropdown 
-------

If there are multiple classes, click on the class name to see clauses only of that class, along with the top 5 class negations. Clicking again goes back to the default view, i.e. all literals.

Clicking a literal highlights only that in the text.
